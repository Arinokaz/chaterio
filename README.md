# chaterio

P2P видеозвонок 1-на-1 прямо в браузере, на чистом WebRTC.
Без бэкенда, без своих серверов, без регистрации.

## Как это работает

Браузеры соединяются между собой напрямую через WebRTC. Для первоначального «знакомства» участников используется **copy-paste сигналинг**: один копирует код-приглашение и отправляет его другу любым способом (мессенджер, почта), друг вставляет у себя, получает ответный код, отправляет обратно. После обмена кодами связь устанавливается, и видео/аудио идут уже напрямую между браузерами.

## Запуск

### Локально (без публикации)

Браузеры разрешают доступ к камере только по `https://` или на `localhost`. Самый простой способ:

```bash
python3 -m http.server 8000
```

Затем открой <http://localhost:8000> в двух вкладках (или в двух разных браузерах).

Если хочешь через Node, в репо уже лежит `server.js` без зависимостей:

```bash
node server.js
```

`Ctrl+C` гасит его чисто (корректно закрывает сокеты). Порт можно поменять переменной окружения: `PORT=3000 node server.js`.

Если ничего из этого нет — `npx serve .` тоже сработает.

### GitHub Pages

Закоммить файлы в репозиторий с включённым GitHub Pages — HTTPS из коробки, можно кидать ссылку друзьям.

## Использование

1. **Инициатор** нажимает «Создать звонок», разрешает доступ к камере и микрофону, копирует появившийся **код приглашения** и отправляет его другу.
2. **Друг** нажимает «Присоединиться», вставляет код приглашения, разрешает доступ к камере. Появляется **ответный код** — копирует и отправляет обратно инициатору.
3. **Инициатор** вставляет ответный код, нажимает «Подключиться» — звонок начинается.

Во время звонка доступны кнопки:
- **Mute / Unmute** — вкл/выкл микрофон
- **Камера / Камера выкл** — вкл/выкл видео
- **Устройства** — открыть панель выбора камеры/микрофона/динамика прямо в звонке (без разрыва соединения)
- **Завершить** — положить трубку

Совет: кликни по коду-приглашению — он выделится целиком, останется только скопировать.

## Устройства

На главном экране есть кнопка-шестерёнка (правый верхний угол). При **первом** заходе экран настроек откроется автоматически — браузер один раз спросит разрешение на камеру и микрофон, дальше его видно не будет.

В настройках:
- живое превью выбранной камеры
- три списка: **Камера / Микрофон / Динамик**
- выбор сохраняется в браузере и применяется ко всем будущим звонкам

Во время звонка нажми **Устройства** — откроется та же панель поверх видео. Смена камеры или микрофона идёт через `replaceTrack` без разрыва соединения; смена динамика — через `setSinkId`. Если вытащил/воткнул вебку в USB — списки обновятся сами.

Список динамиков показывается только если браузер поддерживает `setSinkId` (Chrome / Edge / Firefox 116+ / Safari 17+).

## Ограничения

- Только 1-на-1.
- Используется публичный STUN Google. За симметричными NAT или в строгих корпоративных сетях соединение может не установиться — для пробы технологии достаточно.
- Открытие `index.html` напрямую через `file://` **не сработает**: камера требует безопасного контекста (`https://` или `localhost`).

## Структура

```
index.html   — разметка экранов
style.css    — стили (тёмная тема, видеосетка, оверлей панели устройств)
app.js       — WebRTC-логика, кодеки, выбор устройств, UI
server.js    — локальный статический сервер (Node, без зависимостей)
```
